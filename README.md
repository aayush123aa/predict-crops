## Running the ML Pipeline

[uv](https://docs.astral.sh/uv/) for Python environment and dependency management.

### 1. Prerequisites

Install `uv` if you haven't already:

pip install uv

Install project dependencies:

uv sync

### 3. Run the Complete Pipeline

Execute the scripts in the following order.

**Step 1 — Fetch climate data**

Download historical climate data from NASA POWER:

uv run python src/fetch_power.py --lat $LAT --lon $LON

**Step 2 — Generate monthly climate data**

Process the daily climate data into monthly observations:

uv run python src/make_monthly.py --lat $LAT --lon $LON

**Step 3 — Fetch climate indices**

Download ENSO and Indian Ocean Dipole (IOD) data:

uv run python src/fetch_indices.py

To force a fresh download:

uv run python src/fetch_indices.py --refresh

**Step 4 — Prepare climate indices**

If your project uses a separate index-processing script, run it here. Otherwise, skip this step. The forecasting model reads the generated `data/raw/indices.csv` file automatically.

**Step 5 — Generate climate forecasts**

Train and evaluate the forecasting models, then generate a 12-month forecast:

uv run python src/forecast_model.py \
    --lat $LAT \
    --lon $LON \
    --horizon 12 \
    --test-years 15

**Step 6 — Prepare crop profiles**

Prepare the crop catalogue and generate the processed crop dataset:

uv run python src/prepare_crops.py

**Step 7 — Generate crop scores and rotation recommendations**

Evaluate crop suitability and generate rotation strategies:

uv run python src/score_crops.py --lat $LAT --lon $LON

### 4. Run Everything Together

For convenience, the complete pipeline can be executed using:

LAT=20.0
LON=85.0

uv sync

uv run python src/fetch_power.py --lat $LAT --lon $LON

uv run python src/make_monthly.py --lat $LAT --lon $LON

uv run python src/fetch_indices.py

uv run python src/forecast_model.py \
    --lat $LAT \
    --lon $LON \
    --horizon 12 \
    --test-years 15

uv run python src/prepare_crops.py

uv run python src/score_crops.py --lat $LAT --lon $LON

### 5. Generated Outputs

The pipeline generates processed climate data, forecasts, crop scores and rotation recommendations.


### 6. Run Code Quality Checks

Run Ruff to check Python code:

uv run ruff check src/

Automatically fix supported issues:

uv run ruff check src/ --fix

### 7. Important Notes

- Use decimal latitude and longitude values.
- Use negative latitude for the Southern Hemisphere.
- Use negative longitude for locations west of the Prime Meridian.
- Run the pipeline in the specified order because later scripts depend on files generated by earlier scripts.
- Re-run the climate-data fetching and processing steps when changing locations.
- The crop preparation step currently generates a shared crop catalogue, not a location-specific catalogue.
- Forecasts and crop recommendations are experimental outputs and should be validated against local agronomic data before being used for real farm decisions.
